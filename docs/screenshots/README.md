# Screenshots for README

Add your own screenshots here so they appear in the main [README](../README.md).

| File | What to capture |
|------|-----------------|
| `landing.png` | Landing page (e.g. `http://your-app/dashboard` or `/` before sign-in) — hero, pricing, system architecture |
| `dashboard.png` | Dashboard home after sign-in — Stream Flow, nodes, overview cards |

**How to add:**
1. Open your deployed app (or `http://localhost:3000`) in the browser.
2. Take a full-page or viewport screenshot (e.g. browser DevTools → Capture screenshot, or Snipping Tool / Cmd+Shift+4 on Mac).
3. Save as `landing.png` or `dashboard.png` in this folder.
4. Commit and push; the README will display them automatically.

Recommended size: **1200×700** or **1600×900** for a clear, readable preview.
